# ATmega328P Pedometer using SW-420

## Description
Embedded system project for step counting and distance estimation using the ATmega328P microcontroller and SW-420 vibration sensor. The system detects vibration generated from footsteps and processes the signal to calculate the number of steps and estimated travel distance.

## Features
- Step counting system
- Distance estimation
- SW-420 vibration sensor detection
- ATmega328P microcontroller implementation
- Real-time monitoring

## Components
- ATmega328P MCU
- SW-420 Vibration Sensor
- LED Indicator
- Breadboard & jumper wires
- Power supply
