# Step Counter and Distance Estimation System using ATmega328P and SW-420 Sensor

A simple real-time step counter prototype built using an ATmega328P microcontroller and SW-420 vibration sensor. The system detects human movement through vibration signals, counts steps, estimates travel distance, and displays the results through the Arduino Serial Monitor.

## Overview

This project implements a basic pedometer system using an Arduino Uno (ATmega328P) and an SW-420 vibration sensor. The sensor detects vibrations generated by walking or running movements and sends digital signals to the microcontroller.

Each detected vibration is processed as a step, while the estimated distance is calculated using a fixed step length formula. An LED indicator provides visual feedback whenever a step is detected.

---

## Features

- Real-time step counting
- Distance estimation calculation
- SW-420 vibration sensor integration
- LED step indicator
- Serial Monitor output
- Simple debounce logic to reduce double counting
- Portable prototype powered by USB or powerbank

---

## System Workflow

1. SW-420 detects vibration from movement
2. Arduino reads digital sensor state (HIGH/LOW)
3. System checks transition from LOW → HIGH
4. One valid transition = one step
5. LED blinks briefly as visual feedback
6. Distance estimation is calculated automatically
7. Step count and distance are displayed in Serial Monitor
