## About The Project

This repository contains the complete prototype design and source code for a **real-time step counter and distance estimation system**. Built around an **ATmega328P microcontroller** (Arduino Uno platform) and an **SW-420 vibration sensor**, the device detects human movement through kinetic vibrations, processes the signals using custom debounce logic, computes travel distance, and displays live metrics directly via the Arduino Serial Monitor.

---

## Key Features

* **Real-Time Step Detection:** Converts physical movement vibrations into precise step counts.
* **Distance Estimation:** Calculates approximate travel distance instantly using a calibrated step-length algorithm.
* **Smart Debounce Logic:** Implements transition checks to prevent double-counting or false triggers from noise.
* **Visual Feedback:** Integrated LED blinks momentarily on every valid step registered by the sensor.
* **Portable & Low Power:** Easily powered via USB or a standard 5V mobile powerbank.

## System Workflow

1. **Vibration Detection:** The SW-420 sensor detects mechanical vibration generated by walking or running.
2. **Signal Reading:** The ATmega328P reads the digital sensor state (`HIGH` / `LOW`).
3. **Transition Check:** The firmware monitors signal changes from `LOW` to `HIGH`.
4. **Step Registration:** One valid state transition is logged as **one step**.
5. **Visual Output:** The LED blinks briefly to confirm step registration.
6. **Distance Computation:** Distance is updated automatically based on the step formula.
7. **Serial Logging:** Current step count and total distance are transmitted to the Serial Monitor.

---

## Distance Calculation Logic

The estimated travel distance is computed dynamically using a fixed average stride length formula:

$$\text{Distance (meters)} = \text{Steps} \times 0.75$$
